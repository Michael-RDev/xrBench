Advanced Mode & preset

Every preset runs the full suite. XR mode compares scene-only and scene + layer windows at 72 Hz.

Connecting for the first time?
  1. Enable developer mode and USB debugging on Quest 3.
  2. Connect a data-capable USB cable and allow the prompt inside the headset.
  3. Press Run all tests. The native benchmark app installs automatically.
  4. For XR impact, wear the headset and keep the scene focused.

Other headsets and glasses are not supported yet. Stop takes effect between native work units.
