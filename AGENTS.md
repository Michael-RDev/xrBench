# Agent workflows

When asked to onboard a device to xrBench, follow the
[device onboarding runbook](docs/workflows/device-onboarding.md). It defines the
required identity research, catalog integration, device-specific artwork, public
website checks, scoped hardware qualification, and evidence handoff.

Read the current implementation and preserve existing local changes. Continue
independent work when hardware or release prerequisites are missing, and record
the blocked gates. Catalog entries, demos, and software tests do not establish
physical device support.
