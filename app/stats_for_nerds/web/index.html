How to read these timings

Session stages use one monotonic headset clock and do not overlap. Missing stages are unavailable in older reports. The snapshot excludes the write that publishes it. GPU intervals, native forward, and staging are nested measurements; do not add them to session wall time. Controller transfers and database work use the computer’s clock and are shown separately.

Efficiency ranking

Estimated · calibration-relative

The first run calibrates your device. Profiles are reused when compatible.

What the estimates mean

A versioned cost model estimates arithmetic and logical memory traffic against measured FP32 compute, streaming-copy, and dispatch references. Logical bytes are not measured DRAM traffic. The estimated gap is not a guaranteed speedup or an application-level FPS improvement. Values above 100% exceed the calibration reference. Unsupported models, mismatched conditions, or invalid timings remain unavailable.
