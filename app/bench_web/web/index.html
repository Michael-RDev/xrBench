Preparing

Each layer shows its median latency range across measured input shapes. Expand a layer for individual cases. Warmups and correctness checks are excluded.

Median and p95 include input staging, native Vulkan execution, and output copying. GPU time, when available, sums operation timestamps. Results stay local.
